وقتی می‌خوای با Pyomo مدل‌سازی کنی، اول باید یک **سالور** داشته باشی. سالورهای تجاری خوب، مثل Gurobi و CPLEX، همیشه رایگان نیستند. اما چند گزینه رایگان و قابل‌اعتماد هم وجود دارد. در ادامه سه روش عملی برای نصب و استفاده از این سالورها را می‌بینیم. سپس یک راهنمای انتخاب هم می‌آید: کدام سالور، برای کدام نوع مسئله مناسب‌تر است. (اگر هنوز با مفهوم مدل‌سازی ریاضی پیش از انتخاب سالور آشنا نیستید، یادداشت [مدل‌سازی ریاضی و اهمیت آن](/notes/mathematical-modeling-art/) را ببینید.)

## چهار سالور اصلی که باید بشناسید

پیش از ورود به نصب، بهتر است این چهار سالور را به‌اختصار بشناسیم. هر کدام نقطه قوت متفاوتی دارند.

**GLPK** قدیمی‌ترین و ساده‌ترین گزینه این فهرست است. برای مسائل خطی و صحیح کوچک خوب کار می‌کند، اما برای مدل‌های بزرگ‌تر به‌سرعت کند می‌شود.

**CBC** یک سالور متن‌باز برای برنامه‌ریزی صحیح مختلط (MILP) است. پروژه [COIN-OR](https://www.coin-or.org/) آن را توسعه می‌دهد و سال‌ها گزینه پیش‌فرض بسیاری از پروژه‌های آموزشی بوده است.

**HiGHS** جدیدترین و سریع‌ترین سالور متن‌باز این فهرست است. تیم دانشگاه ادینبرا آن را توسعه داده و امروز در بسیاری از پروژه‌ها، حتی جایگزین CBC و GLPK شده است. HiGHS هم LP و هم MILP را، معمولاً سریع‌تر از CBC، حل می‌کند.

**IPOPT** برای مسائل غیرخطی (NLP) ساخته شده است. اگر تابع هدف یا قیدهای مدل شما غیرخطی باشند، مثلاً شامل توان دوم یا لگاریتم، IPOPT گزینه اول شماست.

**Gurobi** قدرتمندترین سالور تجاری این فهرست است. برای مسائل MILP بسیار بزرگ، از نظر سرعت، معمولاً از همه گزینه‌های رایگان جلوتر است. Gurobi رایگان نیست، اما یک لایسنس رایگان کامل برای دانشگاهیان ارائه می‌دهد.

## ۱) نصب روی کامپیوتر شما (بهترین گزینه برای کار طولانی‌مدت)

اگر می‌خوای این سالورها رو مستقیم روی سیستم خودت داشته باشی، چند مسیر نصب جداگانه وجود دارد.

### نصب GLPK، CBC و IPOPT با Conda

**لازم است:** Anaconda یا Miniconda نصب داشته باشی. دانلود کن از: [anaconda.com](https://www.anaconda.com/)

**سپس کافیه این کامند رو اجرا کنی:**

```bash
conda install -c conda-forge pyomo.solvers
```

این دستور خودکار این سه تا سالور معروف و رایگان رو نصب می‌کنه:
- **GLPK** — خطی و صحیح (Linear & Integer Programming)
- **CBC** — صحیح (Integer Programming) — سریع‌تر از GLPK
- **IPOPT** — غیرخطی (Nonlinear Programming)

⚠️ **نکته مهم:** ورژن Python و Anaconda مهمه. اگر از یک نسخه‌ی خیلی جدید استفاده کنی و بعدش مشکل پیش بیاد، دوباره نصب هم سخت‌تر خواهد بود. بهتره از ورژن Python **۳.۱۰ یا ۳.۱۱** شروع کنی.

### نصب HiGHS

برخلاف سالورهای بالا، HiGHS را معمولاً از طریق pip نصب می‌کنیم، نه conda:

```bash
pip install highspy
```

بعد از نصب، Pyomo می‌تونه از HiGHS از طریق رابط appsi استفاده کنه:

```python
from pyomo.environ import *
from pyomo.contrib.appsi.solvers.highs import Highs

m = ConcreteModel()
m.x = Var(within=NonNegativeIntegers)
m.obj = Objective(expr=m.x, sense=maximize)
m.c1 = Constraint(expr=m.x <= 10)

opt = Highs()
result = opt.solve(m)
print(value(m.x))
```

چون HiGHS کاملاً متن‌باز و بدون لایسنس است، نصب آن ساده‌تر از Gurobi و معمولاً سریع‌تر از CBC است.

### نصب Gurobi و فعال‌سازی لایسنس دانشگاهی

Gurobi به یک لایسنس نیاز دارد، اما دریافت نسخه رایگان آن برای دانشجویان و پژوهشگران دانشگاهی ساده است:

1. در سایت [gurobi.com](https://www.gurobi.com/) با ایمیل دانشگاهی ثبت‌نام کن.
2. از بخش Academic Program، لایسنس رایگان را درخواست بده.
3. با دستور `pip install gurobipy` کتابخانه پایتون را نصب کن.
4. با دستور `grbgetkey` که سایت گوروبی در اختیارت می‌گذارد، لایسنس را روی سیستم خودت فعال کن.

بعد از فعال‌سازی، استفاده از آن در Pyomo تفاوت چندانی با بقیه سالورها ندارد:

```python
opt = SolverFactory('gurobi')
opt.solve(m)
```

**نکته مهم:** لایسنس رایگان دانشگاهی، فقط روی شبکه دانشگاه یا با اتصال VPN دانشگاهی فعال می‌شود. خارج از آن محیط، Gurobi به لایسنس تجاری نیاز دارد.

**بعد از نصب هر سالور، این کد ساده رو برای تست اجرا کن:**

```python
from pyomo.environ import *

m = ConcreteModel()
m.x = Var(within=NonNegativeReals)
m.obj = Objective(expr=m.x**2)

opt = SolverFactory('ipopt')
opt.solve(m)
print(value(m.x))
```

اگر بدون خطا اجرا شد، سالور شما آماده‌ست.

## ۳) سرور NEOS (بدون نصب، حل آنلاین)

برای مسائل کوچک‌تر و یکی‌دفعه، می‌تونی از **NEOS Server** استفاده کنی — یک سرور رایگان دانشگاهی که سالور رو آنلاین اجرا می‌کنه.

**شرط:** اتصال به اینترنت لازمه؛ مدل ترجیحاً کوچک باشه، چون اندازه مدل و زمان اجرا در NEOS محدود است.

**نحوه‌ی استفاده:**

```python
from pyomo.environ import *

m = ConcreteModel()
m.x = Var(within=NonNegativeReals)
m.obj = Objective(expr=m.x**2 - 4*m.x)

# استفاده از NEOS
mgr = SolverManagerFactory('neos')
res = mgr.solve(m, opt='ipopt')

print(value(m.obj))
```

نکته جالب NEOS این است که چند سالور تجاری، مثل CPLEX، را هم به‌صورت محدود و رایگان برای کارهای دانشگاهی در اختیار می‌گذارد. این یعنی می‌توانید بدون خرید لایسنس، نتیجه یک سالور تجاری را روی یک مسئله کوچک آزمایش کنید.

## کدام سالور را انتخاب کنیم؟

این پرسش بیشتر از نصب اهمیت دارد. انتخاب اشتباه سالور می‌تواند زمان حل یک مسئله را از چند ثانیه به چند ساعت برساند. انتخاب درست، اول از همه به نوع مسئله بستگی دارد.

**اگر مسئله شما خطی یا صحیح مختلط (LP/MILP) است:** برای یادگیری و پروژه‌های کوچک، CBC کافی است. اما اگر مدل شما بزرگ‌تر می‌شود، HiGHS را امتحان کنید. در اکثر محک‌ها (Benchmark) سریع‌تر از CBC است و همچنان کاملاً رایگان می‌ماند.

**اگر مسئله شما غیرخطی (NLP) است:** IPOPT تقریباً تنها گزینه رایگان و قابل‌اعتماد در این فهرست است. HiGHS و CBC اصلاً برای مسائل غیرخطی طراحی نشده‌اند و روی آن‌ها جواب نادرست یا خطا می‌دهند.

**اگر مدل شما بسیار بزرگ است یا در یک محیط صنعتی واقعی اجرا می‌شود:** اینجاست که سالورهای تجاری معنا پیدا می‌کنند. صنعتی که شرکت‌هایی مثل ایرلاین دلتا در برنامه‌ریزی ناوگان و خدمه فعال‌اند، برای مسائل MILP بزرگ اغلب Gurobi را ترجیح می‌دهد. سرعت و پایداری عددی آن روی مدل‌های با میلیون‌ها متغیر، هنوز از سالورهای متن‌باز جلوتر است.

**اگر بودجه محدود است اما مدل بزرگ:** قبل از خرید لایسنس تجاری، حتماً HiGHS را روی مدل واقعی خودتان امتحان کنید. فاصله عملکرد آن با سالورهای تجاری، در چند سال اخیر به‌شدت کم شده است.

یک قاعده عملی ساده: همیشه ابتدا با یک سالور رایگان شروع کنید. فقط وقتی به یک محدودیت واقعی سرعت یا مقیاس رسیدید، به سمت Gurobi یا سالورهای تجاری مشابه بروید.

## مقایسه سریع

| سالور | نوع مسئله | لایسنس | سرعت نسبی | مناسب برای |
|---|---|---|---|---|
| **GLPK** | LP, MILP کوچک | رایگان | کند | یادگیری و مدل‌های خیلی کوچک |
| **CBC** | LP, MILP | رایگان | متوسط | پروژه‌های آموزشی و صنعتی متوسط |
| **HiGHS** | LP, MILP | رایگان | سریع | اکثر پروژه‌های واقعی، جایگزین CBC |
| **IPOPT** | NLP | رایگان | متوسط | مسائل غیرخطی |
| **Gurobi** | LP, MILP, QP | تجاری (لایسنس دانشگاهی رایگان) | بسیار سریع | MILP بسیار بزرگ، صنعتی |

| روش اجرا | نصب | سرعت | مناسب برای |
|---|---|---|---|
| **کامپیوتر شخصی** | یک‌بار | ⚡⚡⚡ سریع | پروژه‌های طولانی و بزرگ |
| **Google Colab** | ❌ ندارد | ⚡⚡ متوسط | یادگیری و تست کوتاه‌مدت |
| **NEOS Server** | ❌ ندارد | ⚡ کند | مسائل کوچک و آشنایی اولیه |

قاعده کلی ساده است: برای شروع و یادگیری، از سالورهای رایگان مثل CBC یا HiGHS استفاده کنید. فقط وقتی مدل واقعی شما به یک محدودیت واقعی سرعت رسید، به سمت گزینه‌های تجاری مثل Gurobi بروید.
